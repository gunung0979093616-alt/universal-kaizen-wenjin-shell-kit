# 支援 / Support

## 繁體中文

- 使用問題或一般建議：請開啟 GitHub Discussion（若 Discussions 未啟用，請建立 issue 並選擇最接近的類型）。
- 可重現的錯誤：請使用 **Bug report** issue 範本，附上作業系統、Python 版本、命令與已遮罩的輸出。
- 安全漏洞：請依 [`SECURITY.md`](SECURITY.md) 私下聯絡維護者，不要公開張貼可利用細節或機密。

## English

- Usage questions or general ideas: use GitHub Discussions if enabled; otherwise open an issue and select the closest type.
- Reproducible bugs: use the **Bug report** issue template and include the operating system, Python version, command, and redacted output.
- Security vulnerabilities: contact the maintainer privately as described in [`SECURITY.md`](SECURITY.md). Do not publicly post exploitable details or secrets.
