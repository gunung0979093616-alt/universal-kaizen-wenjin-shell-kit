# 行為準則 / Code of Conduct

## 繁體中文

我們致力於讓每位參與者都能在友善、尊重且安全的環境中合作。請以尊重態度溝通，聚焦問題與證據，歡迎不同經驗與觀點，並給予建設性回饋。

不可接受的行為包括騷擾、人身攻擊、歧視、威脅、羞辱，以及未經同意公開他人個人資訊。維護者可編輯、拒絕或移除違反本準則的內容，並視情況限制參與權限。

若遇到違規情形，請透過 GitHub 帳號 `gunung0979093616-alt` 的私訊聯絡維護者，並附上相關連結與簡要說明。請勿在公開議題中張貼他人私人資料。

## English

We are committed to providing a welcoming, respectful, and safe environment for everyone. Communicate respectfully, focus on the problem and evidence, welcome different experiences and viewpoints, and give constructive feedback.

Unacceptable behavior includes harassment, personal attacks, discrimination, threats, humiliation, and publishing another person's private information without consent. Maintainers may edit, reject, or remove content that violates this code and may restrict participation when appropriate.

To report a violation, contact the maintainer privately through the GitHub account `gunung0979093616-alt` and include relevant links and a short description. Do not post another person's private information in a public issue.
